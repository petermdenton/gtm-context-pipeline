# Identified engagement and relationship paths

Use only when the requested handoff includes engaged-company follow-up or
relationship research. An engagement report alone does not require buying-team
enrichment. Choose the actual client account and configured network/CRM source;
no particular investor network, private host or token path is assumed.

For platform evidence, retain actual reporting window, timezone, filters,
segments, pagination, company IDs, engagement labels and available metrics.
Preserve suppressed values as unknown and report unexamined views. Company
attribution is not person attribution. Rolling-window changes are net changes,
not necessarily daily activity. Reuse comparable snapshots and explain changes.

For relationship paths, use an available authorized source, resolve company and
person identities, and distinguish current staff, former staff, contractors and
similarly named firms. Keep connection strength/date when supplied; a recorded
link does not establish willingness to introduce. Do not transmit unnecessary
engagement exports to a people-search provider.

Use explicit outcomes such as `connection_found`, `no_company_match`,
`no_connections_in_returned_records`, `identity_unresolved` and `unavailable`.
Incomplete pagination is not proof of no connections. Keep connector, connected
person, intended buyer and unknown engager distinct.

Map the buying team using the parent skill. When requested, draft an introduction
request or forwardable note for a credible path, or a direct email otherwise.
Multiple approaches are alternatives unless the user requests broader outreach.
Do not claim endorsement, prior contact or that a named person clicked an ad.

A private handoff can list company, engagement/window, comparison with the prior
compatible snapshot, relationship flag, connector, team coverage, draft state and
next action. A requested introduction note should include the sourced contact
profile, verified role, relevant company-level signal, fit hypothesis and material
relationship/remit gaps. Keep citations alongside the copy. Writing a note does
not authorize posting it to Slack or sending it elsewhere.

Reuse previous research/drafts using stable keys. Keep identity gaps, suppressed
accounts and weak-fit cases visible as holds. Recurring reviews require an actual
requested automation; instructions do not establish a daily job. External drafts,
CRM writes and sends follow [mail/CRM guidance](mail-crm.md).
